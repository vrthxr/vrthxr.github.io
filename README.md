## About

This is my personal portfolio — one of my first projects and one of my earliest hands-on experiences with JavaScript. Things may not be perfect, but it's been a great learning experience and I keep improving it over time.

Built entirely with vanilla HTML, CSS and JavaScript. No frameworks, no libraries — just the fundamentals.

## Features

- Smooth scroll navigation
- About me section
- Projects showcase
- Contact form powered by [EmailJS](https://emailjs.com)
